# LIBRARY

Дом PDF: `library/`  
Наполнение: хронология документов **вплоть до** обзора горизонта · ось Маска.

## Правило

- Только **PDF**.
- Имена с порядковым префиксом `001 · …` = хронологический порядок.
- Манифест: [`library/_manifest.yaml`](library/_manifest.yaml) · [`library/_manifest.json`](library/_manifest.json).
- Чтение: [`README.md`](README.md).

## Граница этого среза

**Включено:** сочинения · каноны · уроки/отчёты зала · google-листы · сказка/этика/брат · горизонт Маска · ось под законом.

**Не включено:** питч Борису · expert-сверки · семейный · ЯБ/бухгалтерия · stamps · netlab кодекс.
